# Synthetic examples

All examples in this directory must comply with [DATA-SAFETY.md](../DATA-SAFETY.md).

The first example set will cover the catalog-to-amended-result vertical slice and
negative cases for an unknown offering, incomplete or unacceptable specimen
information, duplicate submission, rejection, cancellation, and referral.

Each example set should identify:

- Use case and assumptions
- Expected identifiers and relationships
- Expected acknowledgement or error state
- Terminology used
- Framework assertions exercised
- FHIR mapping status, when applicable
- Validation method and result

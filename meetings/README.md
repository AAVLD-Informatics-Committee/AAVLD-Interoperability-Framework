# Meetings

Meeting records in this repository must be public-safe and identify whether an
outcome is a working recommendation, committee decision, or formal AAVLD
approval.

The joint August 26, 2026 pre-meeting agenda covering the symposium,
Interoperability Framework, and IT Guidance decisions is maintained in the
[AAVLD IT Guidance repository](https://github.com/AAVLD-Informatics-Committee/AAVLD-IT-Guidance/blob/00683d0/meetings/AAVLD%202026/2026-08-26%20Informatics%20Committee%20Pre-Meeting%20Agenda.md).

The `2026-10-15-symposium/` directory contains the working symposium agenda,
decision questions, and outcomes record.

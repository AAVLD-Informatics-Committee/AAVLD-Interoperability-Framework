Classifying a source identifies how it may be used. Citation does not by itself
make a source an AAVLD requirement or mandatory implementation technology.

## Source rules

- Preserve authoritative source versions and dates.
- Link to external standards rather than copying them unless redistribution is
  permitted.
- Separate AAVLD requirements, framework requirements, recommendations,
  examples, and implementation-profile constraints.
- Record provisional interpretations as issues until the required authority
  resolves them.
